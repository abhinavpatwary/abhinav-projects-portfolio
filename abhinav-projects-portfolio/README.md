# Abhinav's Projects Portfolio

A minimalist dark portfolio built with Next.js App Router, TypeScript, Tailwind CSS v4, Framer Motion, and Lucide icons.

## Run locally
1. Install Node.js 20.9 or newer.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Visit http://localhost:3000

## Before publishing
- Replace each project's placeholder `codeUrl` in `src/app/page.tsx` with the actual repository URL.
- Add a live deployment URL to `demoUrl` when available. Leave it empty if you don't have a live demo.
- Add your resume PDF at `public/resume.pdf` (create the `public` folder if needed).
- Confirm the LinkedIn URL and email in the footer.
- Update project details so they only describe features actually implemented.

## Deploy
Push the project to GitHub and import the repository into Vercel, or use another Next.js-compatible host.
